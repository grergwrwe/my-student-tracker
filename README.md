# My Python Programming Portfolio 🚀

Welcome to my Python development repository! This project showcases a combined implementation of multiple real-world applications built entirely using **Object-Oriented Programming (OOP)** principles. It represents my practical journey through logic building, structural design, and clean coding practices.

## 📝 Combined Project Overview
This repository features a unified system that integrates three distinct functional modules:
1. **EduTrack-OOP (Student Performance & Attendance Tracker):** An automated evaluation system that tracks academic grades, calculates student performance averages, and cross-checks attendance percentages using strict conditional logic metrics to flag profiles requiring improvement.
2. **School Library Management System:** A structured database simulator designed to manage book tracking, handle real-time borrowing and returning logistics, and maintain precise catalog displays using optimized class relationships.
3. **Bank Account Management System:** A secured banking simulation module handling secure transactions, balance maintenance, deposits, and error-free withdrawal logics.
