# EduTrack-OOP 📊

A clean and efficient **Student Performance & Attendance Tracker** built using Object-Oriented Programming (OOP) principles in Python.

## 🌟 About Me
- **Age:** 16 Years Old (Class 10th) 🚀
- **Goal:** B.Tech in AI and Machine Learning
- **Focus:** Building a rock-solid foundation in DSA, Python, and Data Science.

## 🛠️ Features
- **Object-Oriented Design:** Uses separate `student` and `Tracker` classes for clean, modular code.
- **Automated Analysis:** Calculates average marks using built-in math functions and flags profiles that need attention based on custom logic filters.
- **Criteria-Based Filtering:** Automatically flags students if their average score falls below 50% OR attendance drops below 75%.
